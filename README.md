# CloudSentinel AI

CloudSentinel AI is an intelligent AWS cloud monitoring and incident analysis platform designed to detect abnormal application behavior, classify incidents, analyze potential root causes, and automate cloud alerts.

## Current Architecture

CloudWatch → EventBridge → SQS → Lambda → ML Anomaly Detection → Incident Analysis → DynamoDB → SNS

## Technology Stack

- Python

- Scikit-learn
- AWS Lambda
- Amazon CloudWatch

- Amazon EventBridge
- Amazon SQS
- Amazon DynamoDB
- Amazon SNS
- Amazon S3
- AWS IAM
